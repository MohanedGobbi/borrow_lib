## Exports (staff)
- **`GET /api/exports/books?format=csv|xlsx`** (plus the same `search` / `category` filters as the
  catalog list) exports the whole catalogue.
  - **Columns match the import format**, so an export can be edited and re-imported: `isbn`,
    `title`, `author`, `category`, `publisher`, `year`, `total_copies`, `shelf_location`,
    `description`.
  - Then two read-only columns: `available_copies` and `free_copies`. The import already ignores
    unknown columns; check that a round trip works.
- **`GET /api/exports/loans?format=csv|xlsx&status=...&from=YYYY-MM-DD&to=YYYY-MM-DD`**
  exports borrow records, filtered by status (comma list) and `requested_at` range.
  - Columns: `member`, `student_id`, `email`, `title`, `isbn`, `shelf_location`, `status`,
    `requested_at`, `borrowed_at`, `due_date`, `returned_at`, `renewals`.
  - Datetimes are in `LIBRARY_TIME_ZONE`, as ISO `YYYY-MM-DD HH:MM`.
- **Implementation:**
  - CSV is UTF-8 with BOM (so Excel opens Arabic correctly) and streamed
    (`StreamingHttpResponse`);
  - XLSX uses openpyxl `write_only`;
  - `Content-Disposition: attachment; filename="libborrow-books-2026-10-03.xlsx"`.
- **Formula injection (security):** any text cell whose value starts with `=`, `+`, `-`, `@`, a tab
  or a carriage return gets a leading `'` in both CSV and XLSX. **Test it.**
- **Permissions:** staff and admin only.

## Bulk student import (admin)
- **`POST /api/users/import {rows, dryRun, filename}`**, admin only. Same shape and behaviour as the
  book import:
  - the preview never writes anything;
  - valid rows are saved in one transaction;
  - error rows are skipped and reported per row with codes;
  - a 5,000-row limit;
  - one `STUDENTS_IMPORTED` activity entry.
- **Columns with header aliases in EN, FR and AR** (follow `importing.py`'s alias approach):
  - `name`, or `first_name` + `last_name`;
  - `email`;
  - `student_id`;
  - optional `phone` and `language` (`en`/`fr`/`ar`, default `fr`? **No: default `en`**,
    matching `UserProfile`).
- **Row checks, with codes:**
  - `name_missing`, `email_missing`, `email_invalid`, `student_id_missing`;
  - `email_duplicate` / `student_id_duplicate` inside the file;
  - `student_id_taken` (an existing account with another email);
  - a row whose email already has an account gets the status **`exists`** and is skipped, not
    reported as an error;
  - `language_invalid`.
- **Creating an account:**
  - Django `User` with `username` = email and an unusable password;
  - a MEMBER profile with `email_verified=False` and the language.
  - After commit, send a **welcome email** (new `send_welcome` in `emails.py`, EN/FR/AR):
    "Your library account is ready: set your password", with the password-reset link. Its
    validity is `PASSWORD_RESET_TIMEOUT`. Mention "Forgot password?" for an expired link.
  - Reuse one SMTP connection for the batch (`get_connection()` + `send_messages`).
  - **Setting a password through a reset link now also sets `email_verified=True`**, because the
    link proves the address. This also helps WP-08 users.
- **CLI:** `python manage.py import_students file.xlsx [--dry-run]`, like `import_books`.
